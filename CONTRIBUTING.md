# Contributing

We welcome clear documentation, corrections, practical preservation guidance, and reproducible examples using synthetic data.

For technical guidance, link the relevant publisher's documentation and state the versions tested. Distinguish a proposal from a feature that has been built, installed, or observed working.

Do not submit operational source, server inventories, credentials, player records, raw private logs, or unredacted incident evidence. Use reserved documentation addresses, `.invalid` hostnames, and fictional accounts in examples. Report sensitive issues privately; see [SECURITY.md](SECURITY.md).

For community questions or private contact, start at [MCrashCraft](https://mcrashcraft.com/).
