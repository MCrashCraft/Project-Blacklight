# Project Blacklight

**Illuminate. Preserve. Recover.**

Project Blacklight (PB) is a MCrashCraft initiative to help protect Minecraft communities and preserve their history. We help server owners understand security risks, preserve worlds, validate backups, and recover after damage or griefing.

## What we do

- Review server observations and help owners understand exposed services.
- Encourage account verification, whitelists, careful permissions, and secure hosting.
- Help preserve worlds through owner-approved exports or documented client captures.
- Help owners check backup integrity and test recovery in an isolated environment.
- Document incidents, restoration work, and before/after evidence.

The private Blacklight platform brings together a dashboard, API, Discord tools, and a verified Minecraft client. Development is ongoing; this repository describes the project and practical guidance, rather than promising that every planned workflow is deployed. An inventory entry, a successful connection, and a verified backup are separate pieces of evidence.

## Protect your server

Start with these guides:

1. [Enable a whitelist and secure a Java server](docs/WHITELIST-AND-SECURITY.md).
2. [Understand offline-mode risks and server-side authentication](docs/AUTHME-AND-OFFLINE-MODE.md).
3. [Make backups you can actually restore](docs/BACKUPS-AND-RECOVERY.md).
4. [Follow the preservation and restoration workflow](docs/PRESERVATION-WORKFLOW.md).

A reachable server is not necessarily intended to be public. A player name or stream link does not establish ownership, permission, or a security incident. We review evidence and contact intentions before making claims or beginning preservation work.

## Get involved

Visit [MCrashCraft](https://mcrashcraft.com/) to learn about the community and ask about Project Blacklight. Documentation improvements are welcome; see [CONTRIBUTING.md](CONTRIBUTING.md).

This public repository contains documentation. Operational source, server inventories, credentials, production configuration, and private incident evidence are kept outside it. Please do not put server addresses, player records, passwords, tokens, or unredacted logs in public issues. See [SECURITY.md](SECURITY.md) for reporting guidance.
