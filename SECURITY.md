# Security and private reports

Do not publish passwords, tokens, authentication databases, server inventories, player records, or private incident evidence in issues or pull requests.

Start a private conversation with the project through [MCrashCraft](https://mcrashcraft.com/) to agree on a reporting channel. Begin with a brief description and affected component; share sensitive evidence only after the private path is agreed.

This repository contains public documentation. It does not provide access to the private Blacklight platform or authorize testing of other people's servers.
